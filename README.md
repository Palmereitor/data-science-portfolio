# Daniel Palmera — Data Science Portfolio

Operations and data professional with a systems-minded approach. This portfolio covers four end-to-end projects built during the Soy Henry Data Science program, spanning data engineering, machine learning, business intelligence, and cloud architecture.

## Projects

### M1 — Boston Restaurant Recommender
Recommendation system built on Yelp API data for the Boston market. Hierarchical imputation strategy for missing data, weighted scoring model combining rating, review volume, and price tier, and exploratory analysis of 1,000+ restaurants across 15 neighborhoods.

**Stack:** Python, pandas, Yelp API, Jupyter

---

### M2 — FleetLogix: SQL & Cloud Data Engineering
End-to-end data pipeline for a fleet management company. Star schema data warehouse design, SQL analytics layer, MongoDB IoT telemetry ingestion, and AWS cloud architecture (Lambda, RDS, S3, DynamoDB, API Gateway, CloudWatch).

**Stack:** PostgreSQL, MongoDB, AWS, Python, SQL

---

### M3 — TechCore: Power BI Sales Analytics
Business intelligence system for a retail technology company. Power Query ETL pipeline (30,307 → 30,000 clean records), normalized relational model with 7 tables, interactive 3-page executive dashboard, and Row-Level Security with 3 roles.

**Stack:** Power BI, Power Query, DAX, Python, pandas

---

### M4 — FinanceGuard: ML Churn Prediction
Binary churn classification system for a financial services company. Five models evaluated (Logistic Regression, Random Forest, XGBoost, LightGBM, CatBoost) plus a Stacking ensemble. Threshold optimization for business impact: projected $46,200 savings per intervention cycle. Unsupervised segmentation with K-Means (K=3) and DBSCAN.

**Key metrics:** Stacking AUC 0.8709 | F1 0.6139 | Recall 0.7813

**Stack:** Python, scikit-learn, XGBoost, LightGBM, CatBoost, Optuna, pandas, Jupyter
